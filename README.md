# 🛡️ Proxy Master

**Claude через твой прокси, и ничего лишнего наружу**

Claude Code, Claude Desktop и браузер для Claude работают через твой зарубежный прокси.
Программа следит, чтобы Claude видел страну прокси во всём: в адресе, часовом поясе и
языке браузера.

## 💡 Зачем это нужно

Claude не работает напрямую из России. Обычное решение - зарубежный прокси, но одного
его мало:

- **Claude Desktop и VS Code** не умеют работать с прокси, где нужны логин и пароль.
- **Claude видит не только адрес.** Часовой пояс компьютера, русский в списке языков
  браузера, видеозвонки в браузере мимо прокси выдают, где ты на самом деле. Такое
  несовпадение - повод проверить аккаунт.
- **Прокси может упасть или сменить страну**, и тогда Claude увидит другой адрес.

Proxy Master закрывает всё это и сам следит, чтобы так и оставалось.

---

## ✨ Что умеет

- 🔐 **Свой прокси для Claude.** Claude Code, Claude Desktop и браузер для Claude
  выходят в интернет только через него, и больше через него не ходит ничего.
- 🧱 **Автостоп.** Прокси для Claude замолчал или сменил страну - Claude ждёт без
  интернета и не выходит в сеть с другого адреса.
- 🌐 **Claude только в одном браузере.** В остальных браузерах сайт Claude закрыт.
  Расширения в браузере для Claude выключены: они могли бы читать переписку.
- 🛡️ **Вкладка «Безопасность».** Проверяет видеозвонки, соединения мимо прокси,
  расширения и язык браузера. Русский из браузера для Claude программа убирает сама.
  Отчёты с именем компьютера не уходят в Anthropic.
- 🕒 **Часовой пояс прокси** для Claude Code, Claude Desktop, браузера для Claude и
  выбранных программ.
- 🧩 **Вкладка «Программы».** Любую программу можно пустить через выбранный прокси.
- 🗺️ **Вкладка «Сайты».** Нужный сайт - через отдельный прокси в выбранном браузере.
  Там же блокировка рекламы и счётчиков слежки.
- 🔄 **Обновления** программа проверяет сама и ставит по твоему клику.

## 🧭 Как это работает

```text
Claude Code, Claude Desktop,          ┌────────────────┐      ┌─────────────────────┐
браузер для Claude  ────────────────▶ │                │ ───▶ │  Прокси для Claude  │ ───▶  Claude
                                      │  Мост на твоём │      └─────────────────────┘
Программы и сайты,  ────────────────▶ │   компьютере   │ ───▶  их прокси
которые ты выбрал                     └────────────────┘

Всё остальное работает напрямую, как раньше.
```

Мост подставляет логин и пароль прокси сам, поэтому программам ничего не нужно знать
про авторизацию.

## 📥 Установка

Понадобится зарубежный IPv4-прокси HTTP или SOCKS5 с логином и паролем: вставь строку
от продавца целиком, тип и страну программа определит сама.

### 🖥️ Windows 10 / 11 (64-бит)

1. Скачай `Proxy-Master-Windows.exe` из [**последнего выпуска**](../../releases/latest).
2. Запусти. Если Windows покажет SmartScreen: «Подробнее» → «Выполнить в любом случае».
3. Добавь прокси для Claude и выбери браузер для Claude. Windows один раз спросит права
   администратора: так включаются защита от утечек и настройки браузеров.

### 🍎 macOS (Apple Silicon: M1 и новее)

> **Нужен Mac на M1, M2, M3, M4 или новее и macOS 11 или новее.** На Mac с процессором
> Intel программа не откроется. Проверить: меню Apple → «Об этом Mac» → строка «Чип».

1. Скачай `Proxy-Master-macOS.dmg` из [**последнего выпуска**](../../releases/latest),
   открой и перетащи Proxy Master в «Программы».
2. Первый запуск - один раз разреши открыть программу, она собрана без сертификата Apple:
   - macOS 15 и новее: «Системные настройки» → «Конфиденциальность и безопасность» →
     «Всё равно открыть»;
   - macOS 14 и старше: правый щелчок по Proxy Master → «Открыть» → «Открыть».
3. Добавь прокси для Claude и выбери браузер для Claude. macOS один раз спросит пароль
   администратора.

Программа запускается вместе с системой: без неё после перезагрузки Claude увидел бы
твой настоящий часовой пояс. Если VS Code или терминал были открыты во время установки,
перезапусти их.

## ⬆️ Обновления

Программа проверяет обновления сама и ставит их по твоему клику: «Настройки» →
«Обновления». Если у тебя стоит Claude-Proxy-Tunnel 0.5.8: «Настройки» → «Проверить
обновления», настройки и прокси переедут сами.

---

## 🧹 Удаление

- **Windows:** «Инструменты» → «Открыть мастер удаления» или «Параметры» → «Приложения»
  → Proxy Master.
- **macOS:** «Инструменты» → «Удалить программу».

Удаляется только то, что поставила программа: мост, защита от утечек, настройки
браузеров, прокси в настройках Claude Code и VS Code. Claude Code и Claude Desktop - по
твоему выбору.

## 🩺 Если что-то не работает

| Что видно | Что делать |
|---|---|
| Значок в трее **жёлтый** | Мост запускается или проверяет прокси. Подожди минуту: «Обзор» покажет, что происходит |
| Значок **красный** | Нет связи с прокси, сработал автостоп или порты заняты другой программой. Открой программу: на «Обзоре» будет причина и кнопка, что делать |
| Прокси не проходит проверку | Проверь у продавца: оплачен ли прокси, верны ли логин и пароль, нет ли привязки к IP |
| Claude Code не отвечает сразу после установки | Перезапусти VS Code или терминал |

## 🔒 Приватность

- Через прокси для Claude идёт только Claude. Остальные программы и сайты работают так,
  как ты настроишь, по умолчанию напрямую.
- Отчёты Claude с именем компьютера и сведениями о железе программа блокирует.
- Своей статистики программа не собирает. Прокси и настройки хранятся только на твоём
  компьютере.

⚠️ Обход географических ограничений через прокси может нарушать условия сервисов.
Используй на свой страх и риск.
